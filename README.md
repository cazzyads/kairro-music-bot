# 🎵 Telegram Music Bot

Bot musik Telegram untuk mencari dan memutar lagu ke Voice Chat.

## 🎧 Fitur

- `/start` — membuka menu bot
- `/play judul lagu` — mencari lagu dari YouTube
- `/play URL` — memutar URL YouTube/SoundCloud
- `/sc judul lagu` — mencari lagu dari SoundCloud
- `/skip` — skip lagu
- `/stop` — menghentikan musik
- `/pause` — pause
- `/resume` — melanjutkan musik
- `/queue` — melihat antrean lagu
- Queue terpisah untuk setiap grup
- Otomatis memainkan lagu berikutnya
